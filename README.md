# Santorini

Sitio web construido con [Next.js](https://nextjs.org/) (App Router).

## Características

- Página principal con imagen a pantalla completa y recortes superpuestos enlazados a cada colección.
- Páginas individuales: `/aurora`, `/clio`, `/hebe`.
- Catálogo con todas las disponibles: `/catalogo`.
- Página de eventos: `/eventos`.
- Sección de servicios y mapa de Google.
- Botón flotante de WhatsApp.
- Diseño responsive con posicionamiento independiente de imágenes para móvil.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Producción

```bash
npm run build
npm start
```
